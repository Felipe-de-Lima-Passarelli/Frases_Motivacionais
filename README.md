# 🌟 Projeto Frases Motivacionais - Gerador de Inspirações

O **Projeto Frases Motivacionais** é uma aplicação simples desenvolvida com **HTML, CSS, JavaScript e Bootstrap**, que exibe frases motivacionais aleatórias ao clicar em um botão.  
É um projeto ideal para praticar **manipulação do DOM**, **eventos em JavaScript** e o uso básico do **Bootstrap** para estilização.

---

## 🛠️ Tecnologias

* HTML5  
* CSS3  
* JavaScript  
* Bootstrap 4  

---

## 🔍 Funcionalidades

* Exibição de uma frase motivacional inicial.  
* Botão que gera uma nova frase aleatória.  
* Estrutura responsiva utilizando Bootstrap.  
* Manipulação dinâmica de texto via DOM.  
* Seleção randômica de frases através de array JavaScript.  

---

## 💻 Como usar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/frases-motivacionais.git
```
2. Entre na pasta:
```bash
cd frases-motivacionais
```
1. Abra o arquivo:
```bash
index.html
```

## 🔧 Aprendizados
